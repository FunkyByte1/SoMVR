# finishers.txt - the VR finishers: the game's own paired kills as 1-3 guided motions of the player's sword
# (docs/re-xr-pipeline.md 140 the framework, 149 this table). Build 34 data: SOMVR_FINISHER (140) does not read it yet -
# its loader is the next round's; [neck] is the neck stab exactly as 140 built it, the others drop in beside it.
#
# Every time is ms in Talion's half's animation (its keys at 30 fps, read from the game's .anix sets by tools/anix.py);
# lengths are the animations' own. The records are the game database's (logs/boot-check-20261020-001117/probe-out/
# attacks-full.tsv). One block per finisher: [id], then `key = value` lines:
#   source    Talion's record (PC_*): the sync's source and the death's DealHit record
#   target    the orc's record (AI_*): its half, played on the orc (SOMVR_KILLS' start; 140's SOMVR_FINISHER_ROW)
#   sync      the Combat/Sync record pairing them
#   talion    Talion's half: animation, length ms, set - never played in VR (no body or view move): its path is the
#             player's to follow
#   orc       the orc's half: animation, length ms, set
#   ready     state (fighting | stunned | downed | captain) and side (front | back: the orc's front or back to Talion
#             within 70 deg), the game's pick for it (the selection's node, or the record when the pick is ours)
#   orc_root  the orc's half moves its root this far over the whole animation (cm) and turns it (deg) [med: the
#             animation record's end transform; 140's boot 164142 saw F6's orc moved ~1 m - here 122 cm]
#   orc_keys  the orc's half: ALLOWRAGDOLL / RESUMERAGDOLL (ms in its own animation), its wound (the game's blood on it)
#   slowmo    the game's own slow-motion window(s) (BSLOWMO..ESLOWMO, Instakill_01_SM)
#   kill      APPLYDAMAGE (or AD) times; sever = SEVER times (the head comes off)
#   motion    one guided motion, in order (1-3), `key=value` tokens:
#             kind   stab (in and out on one line: 140's p 0..2) | in (in only: the blade stays in for the next) |
#                    cut (along a path through the node)
#             node   the orc's node it goes into or through (Pelvis | Torso | Neck | Head: stl_body's four)
#             at     the game's contact moment (the blood key's time)
#             rec    the window to cut the recorded path from (a first cut from the keys around `at`)
#             hit    - | hit (an APPLYDAMAGE that does not kill: blood, haptic) | kill (the death blow: 140's way in) |
#                    sever (the head off where the blade crosses the node; with kill when it also kills)
#             blood  the game's MeleeFX names at the contact (in,out for a stab): BloodSA_<size>_Weapon<Mid|Tip>_
#                    <Inward | Outward | Trail | TrailRev | Tangent | TangentRev> = the spray along the blade's way
#             path   line (140's geometric line fitted to the grip: start_cm, depth_cm) | the recorded tip path
#                    `x,y,z;x,y,z;...` (cm, 16 points by arc length, in the node's frame at the motion's start: the
#                    orc's right, up, ahead) | empty = to be recorded (re-xr-pipeline.md 149.4)
